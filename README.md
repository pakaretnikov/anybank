# anybank

## Structure
- `lib/app` — composition root, routing, app config
- `lib/core` — cross-cutting concerns (theme, DI, constants, utils)
- `lib/features` — feature modules (data/domain/presentation)
- `lib/shared` — reusable widgets and design system pieces
- `docs` — architecture and conventions
- `test` — unit and widget tests

## Getting started
1. `flutter pub get`
2. `flutter run`
